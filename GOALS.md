# Goals

## Primary Goal
Ship 《瑟瓦納：森林的抉擇》 v0.1.0, a complete free, browser-local turn-based RPG hosted on GitHub Pages.

## Non-goals
Paid services, accounts, backend, telemetry, multiplayer, or unverified claims about Tsou culture.

## MVP Acceptance Criteria
- New game, manual/autosave, validated load, reset, and local-only progress.
- Eight main chapters from 迷霧中的瑟瓦納 to 敬畏的誓言, with a playable ending.
- At least five side quests; nine implemented for a 3×3 environmental action grid.
- Exploration, NPC dialogue, clue discovery, choices with reasons/consequences, and a player-written pledge.
- Turn-based attack, defend, reflect, skill, item, and flee; fictional enemies and boss.
- EXP, level cap 10, stat growth, inventory, equipment, unlockable skills, achievements.
- Desktop/tablet/mobile layouts and keyboard-accessible interactions.
- Full-run domain tests, validation/build checks, and browser QA.

## Cultural Rules
Only verified cultural records may be presented as source-based content. Missing source material is TODO_CULTURE_REVIEW. The first release plays an explicitly original environmental story; it does not certify cultural accuracy or pretend that pending content is reviewed.

## GitHub Pages Completion
Public repository, clean main pushed, official Actions deployment successful, Pages build_type=workflow, and live document/module/style/art URLs verified.
